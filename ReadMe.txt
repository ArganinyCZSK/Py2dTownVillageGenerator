Map Generator: Features & Capabilities

Map Generation

Generates 2D maps of villages or towns, including houses, churches or town halls, roads, dirt paths, streetlights, walls, fences, fields, forests, and ponds.

Towns feature defensive walls with towers and gates, along with a central square. Villages have a village green with a small pond.

Each map receives a randomly generated name and a seed number. Using the same seed will generate the exact same map again.

Settings (Left Panel)

Adjust map and settlement size, the number of roads and streets, and building density and size.

Enable or disable defensive walls, streetlights, town squares, and churches.

Control the amount of fields, pastures, forests, trees, fences, and walls.

Customize the appearance, including grass textures, shadows, streetlight illumination, map titles, legends, and scale bars.

Map Editing

Drag and drop houses, trees, streetlights, fields, or ponds to reposition them.

Rotate objects using the mouse wheel or the Q and E keys.

Delete objects using the Delete key or right-click.

Add houses, streetlights, trees, wooden fences, brick walls, and stone walls.

Undo changes using Ctrl+Z.

Map Image Import

Converts PNG or JPG images of real-world maps into fully editable maps.

Automatically detects buildings, roads, highways, dirt paths, water bodies, forests, gardens, and fields.

Supports both historical topographic maps (e.g., from 1952 or 1963), automatically identifying the map style.

Export

Saves exported files directly to the folder where the program is located.

PNG, BMP, PPM: Raster images with adjustable export scaling from 1× to 4×.

SVG, EPS: Vector formats suitable for printing and unlimited scaling without quality loss.

JSON: Saves the complete map data, allowing it to be reopened and edited later.
